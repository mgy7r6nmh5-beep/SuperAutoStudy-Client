i怎么看进度

    

    

      后端没有查询进度的接口，进度写在数据库里。用下面的命令看（在
      SuperAutoStudy 目录下执行）：
    

    
mysql.exe -u root -pSuperAuto2026 tihai -e "SELECT course_name,current_job,current_progress,status,error_message,start_time FROM th_wk_log ORDER BY id DESC LIMIT 20;"


    


    
状态码对照

    

      0 待处理
      1 进行中
      2 队列中
      3 考试中
      4 已完成
      5 异常
      6 暂停
    


    


    
常见情况

    

      
日志出现「用户未登录」

      
登录写入是异步的，点一次「重新扫描队列」即可

      
提交后提示「任务已存在」

      
同一账号 + 同一课程已有记录，不会重复提交

      
获取课程列表失败

      
账号密码错误，或超星要求验证码（本工具不支持验证码）

      
倍速

      
默认 3 倍，改 application-dev.yml 的 study.chaoxing.speed
